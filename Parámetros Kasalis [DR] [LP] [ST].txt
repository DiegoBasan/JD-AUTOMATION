[SEQUENCE]
# The sequence of dispense operations.  Multiple pre-inspection operations are supported using the PAT and PRE
# operations.  Multiple dispense operations are supported using the DOT, LIN, and ARC operations.  Multiple post-
# inspection operations are supported using the VIS operation.  Multiple particle detection operations are supported,
# if available on the system, using the PRT operation.  Stepped UV cure operations are supported, if available on the
# system, using the UV operation.  Finally, a single external library vision inpsection is supported, if available fo
# for the system, using the EXT operation.  All dispense function position and distance arguments are expressed in
# millimeters or degrees and are relative to the calibrated dispense tip position.  The pre-inspection PRE operations
# are always executed first before any other operations, in the order that they are defined.  All other functions are
# then executed in the order that they appear in the sequence.  All dispense and post-dispense inspect and EXT
# operations are performed at the pre-inspect X, Y, and Z position specified by the pre-inspect PRE operation referenced
# by their IN argument.  UV operations are performed independently of the other operations and occur at either the alignment
# or spare stations.  The VIS and EXT operations also contain optional XO, YO, and ZO paramaeters expressed in millimeters
# relative to the referenced pre-inspect position.  Only the result from the last executed EXT function will be recorded
# in the device data record fields pertaining to this inspection.
#

# RIT : Performs relative illumination / dark corner test at the spare station.  For relative illumination, the
# test measures the illumination at the center and four corners of the image and calculates relative illumination
# for each corner as the corner measurement divided by the center measurement expressed as as a percentage.
# For dark corner, the test measures the illumination at the four corners of the image using two specified
# ROIs where the first ROI is the RCN parameter and the second ROI is the DCN parameter.  Dark corner is
# calculated for each corner as the illumination in each corner defined by the DCN parameter divided by the
# illumination in each corner defined by the RCN parameter.
# NOTE: To specify specific camera registers to set prior to performing the relative illumination / dark corner
# test include a section in the CameraFileSpare file called [Relative Illumination Test Pre], and to specify
# registers to set after performing this test include a section in the CameraFileSpare file called
# [Relative Illumination Test Post].
#################################################
# LW  : vision light delay (0 to 1000 ms)
# LD  : vision light intensity for dome light (0 to 100% where 0% disables the light)
# TTR : relative illumination test threshold - minimum allowed test value to produce a PASS test result
# TTD : dark corner test threshold - minimum allowed test value to produce a PASS test result
# RCT : width and height of the center ROI in pixels
# RCN : width and height of the relative illumination corner ROIs in pixels
# DCN : width and height of the dark corner ROIs in pixels - ROIs will be positioned at outer extent of the RI ROIs
# RX : percentage distance from image center to left / right boundary of image to position corner ROIs where 100% would have outer edge of ROIs at first / last column of image
# RY : percentage distance from image center to top / bottom boundary of image to position corner ROIs where 100% would have outer edge of ROIs at first / last row of image
# RIT EXAMPLE: RIT LW=100,LD=50,TTR=0.5,TTD=0.8,RCT=12,RCN=12,DCN=6,RX=100,RY=100
